# Scape v0.9 Master Roadmap
Generated from 9 gap audits · 2026-04-22

## Executive summary

The 9 audits converge on a single meta-pattern: **Scape's content catalog has surface volume but load-bearing data wiring is missing or silent.** v0.8 shipped 2,698 DAG nodes, 2,117 catalog activities, 220 quests, 525 methods, 320 diary tasks, 331 CAs, and 947 monsters — the skeleton is complete. What's broken is the nervous system.

The first 30-day diagnostic proved this: an unlimited-attention bot completed **0 of 220 quests**, touched **6 of 2,117 activities**, and achieved `low/unlim = 0.023` against a 0.2-0.4 target. The sim cannot see the content because:

1. **Quests don't expose machine-readable rewards** — 216/220 lack `unlocks`/`chain_next` fields (only trailing prose comments).
2. **210 DAG refs are broken** — 60 area nodes missing, 21 prefix-drift typos, 17 pending quests.
3. **46.9% of monsters (444/947) have zero drops** — killing them is a null action.
4. **Diary achievements gate nothing** — 32 diary completion nodes exist; 0 downstream nodes require them.
5. **Two collection-log catalogues disagree** — 209 JSON entries vs 143 orphan pets-collection.js entries.
6. **401 stub gp-values (1-999 gp)** + one 3.75B overflow corrupt the moneymaking picture.
7. **506 misery zones** (293 stub_data) make ~24% of activities dominated.

**v0.9 must close the nervous system before adding more volume.** Every CRITICAL task below fixes a silent-breakage problem that prevents the diagnostic (and future bots) from perceiving the game.

## Parallelization plan

Each wave targets non-overlapping files so agents don't collide. Tasks serialized within a wave depend on the previous wave landing.

### Wave A — Foundation fixes (single-agent, blocks everything)

Run first, sequentially, on main. These rewrite heavy data files that later waves extend.
1. **C15** (DAG lint) — enables earlier error detection.
2. **C5 + C7 + C1 + C2** (quest codemods + DAG renames + retracts) — shared concern: quest-reward shape. One agent, one session.
3. **C6** (60 DAG area nodes) — large, mechanical, one agent, `data/progression-dag.json` only.
4. **C10** (coll-log reconciliation) — must land before any coll-log expansion.
5. **C3 + C4** (stub quests + quest XP floors) — same quest files.

### Wave B — 5 parallel agents (non-overlapping files)

After Wave A. Each agent has its own file scope.
- **Agent B1: Drop tables.** `data/drop-tables.json`. Tasks: **C12** (84 new tables) + **H9** (rare rebalance) + **H10** (20 bosses + unique) + **H15** partial (444 zero-drop monsters).
- **Agent B2: Combat achievements.** `src/content/aelgard/combat-achievements-tasks.js`. Tasks: **H4** (99 CAs across 33 bosses) + **H5** (120 Master/GM CAs).
- **Agent B3: Diary expansion.** `data/diaries/*.json` + `src/content/aelgard/achievement-diaries.js`. Tasks: **H1** (Wilds diary) + **H2** (10→15 per cell) + **M8** (reward variety) + **M9** (bank teleports) + **M10** (task variety).
- **Agent B4: Collection log expansion.** `data/collection-log.json`. Tasks: **H6** (51 boss ports) + **H7** (4 minigames) + **H8** (Easy clue) + **H14** (rate rebalance) + **H16** (raid expansion) + **M4** (skilling pets) + **M5** (Other).

- **Agent C1: Planner.** `src/sim/goal-planner.js`. Tasks: **C8** (quest pursuit) + **C9** (novelty term) + **M11** (XP rollup). Depends on C1-C2 landing from Wave A.
