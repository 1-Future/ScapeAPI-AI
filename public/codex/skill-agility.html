Breakpoints

  • level 10 Run energy restores faster. The world stops feeling sluggish.
    unlocks: Draynor rooftop agility course
  • level 40 Several key shortcuts unlock. The Falador dungeon shortcut saves minutes per trip.
    unlocks: Falador dungeon pipe shortcut
  • level 52 Wilderness agility course opens. The one-way escape route. The dispenser at the end drops skull-gold each lap.
    unlocks: Wilderness agility course
  • level 60 Dune-vault speed run opens. The sand becomes a musical instrument. The marks of grace rain down if the tempo holds.
    unlocks: Dune-vault speed run
  • level 70 Most endgame shortcuts accessible. God Wars Dungeon shortcut. Bossing efficiency jumps.
    unlocks: God Wars Dungeon agility shortcut
  • level 70 Wilds shortcut network fully usable. Every shortcut chained into one route. Escape becomes a skill the agility-capped keep.
    unlocks: Wilds shortcut network
  • level 75 Deep gearwalk unlocked. 80k agility XP/hr + pumpman seals. The tick-perfect endgame Sootworks course.
    unlocks: Deep Gearwalk elite run
  • level 92 Hallowed Sepulchre floor 5. The best agility training in the game and one of the best money-makers.
    unlocks: Hallowed Sepulchre floor 5 — best agility XP + profit
